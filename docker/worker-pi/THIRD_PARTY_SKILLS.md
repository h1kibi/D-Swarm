## Patches applied to the vendored copies

- yaklang playbooks: cross-skill routing links are kept only when they point
  at a vendored sibling; references to non-bundled yaklang skills are removed
  (or marked "not bundled in this image").
- ljagiello skills: relative `scripts/install_ctf_tools.sh` references are
  rewritten to the image path `/opt/dswarm/ctf-tools/install_ctf_tools.sh` (the installer is
  vendored at `docker/worker-pi/scripts/install_ctf_tools.sh`).
- zhaoxuya520/reverse-skill modules: cross-module references are kept only
  when they point at a vendored module or a vendored shared dir  (field-journal, references, scripts, config, ops); the upstream `tool-index.md.template`
  is vendored as `tool-index.md` so the modules' tool-index instruction
  resolves.

Reverse-skill shared infra (no SKILL.md, referenced via `../`): directions/rev/skills/field-journal, directions/rev/skills/references, directions/rev/skills/scripts, directions/rev/skills/config, directions/rev/skills/ops.

Re-vendor with: `python docker/worker-pi/scripts/vendor_external_skills.py`
